Hot keys

      

        
Enterrun the command

        
↑ / ↓the command you typed before / after

        
Tabfinish a file or folder name for you

        
Home / Endjump to the start / end of the line

        
Ctrl+Lclear the screen

        
Ctrl+Uerase the whole line

        
Ctrl+A / Ctrl+Ego to the start / end of the line

        
Escerase the line

      

      
Tip: you never type the ( ) brackets you see in lessons.
