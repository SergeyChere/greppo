# Greppo

A safe, kid-friendly game for learning the **Linux terminal**, right in the browser.

Children explore a pretend file system with real commands (`ls`, `cd`, `cat`,
`mkdir`, `echo`, `rm`, `find`, `grep`, …), first learning each command and then
recalling it from memory. Collect the hidden letters, spell the secret word, and
watch your ASCII pet **Greppo** evolve from egg to MEGA across three levels.

Nothing on a real computer is ever touched — the whole file system lives in
memory.

## Play

It's a single self-contained `index.html`. Open it in any modern browser, or
play the hosted version via GitHub Pages.

## Features

- 3 story levels with a Matrix-style intro and transitions
- Learn-then-recall lessons, checkpoints and a mastery meter
- An evolving, animated ASCII pet that motivates finishing the quest
- A free-play **Sandbox** mode with easter-egg commands (`meow`, `dance`,
  `rainbow`, `fortune`, …) and mini-games: tic-tac-toe, battleship, sudoku
- Keyboard practice: `Enter`, `↑` history, `Tab` completion
- Progress saved locally in the browser
